# T6 ROSA → 온프렘 DR (Site DR) — 실측 결과 (2026-10-16)

> **판정: 기술 검증 PASS (실측 범위 내).** ROSA 쓰기를 차단하고 온프렘 DB를 승격한 뒤 Route 53 판단을 바꿔 사용자 요청을 온프렘 DR로 전환했다. 사이트 전환(DNS)은 최초 17.8초, 안정 약 23.8초였다.
>
> **중요:** 승격 후 RDS GTID가 계속 증가해 사용자 쓰기 재개를 **일부러 보류(STOP)** 했고, RDS 자체 heartbeat임을 확인한 뒤 재개했다. 따라서 "쓰기 불가 구간 53분 49초"에는 **운영 판단으로 늦춘 시간**이 포함되며, 하나의 "User RTO"로 합쳐 쓰지 않는다.

기준: [통합 장애 시연안 PR #123](https://github.com/neuroplan-hybrid/neuroplan-aws-migration/pull/123)의 번호 체계(T6 ROSA → 온프렘 DR). 시각은 모두 KST이며, 희재 시각은 서버 로그·CSV 기준, 정현·예린 시각은 메시지 보고 기준이다. 계정 ID·IP·HC ID·엔드포인트·테스트 계정은 적지 않는다.

## 4. GTID 증가 STOP과 판정

- 증상: 승격(11:47:00) 이후에도 RDS GTID가 `4639` → `4640`~`4646`으로 증가. 승격 후 RDS에 쓰기가 계속 들어오면 유실·split-brain 위험이 있어 쓰기 재개를 멈춤
- 후보 제외: k6(12:00:35.959 중지 후에도 증가), 로그인 확인 루프(12:06:43 종료 후에도 12:11:45~12:12:15에 `4645 → 4646`). 약 34분에 7회, 5분 안팎 주기
- 원인(정현 보고): GTID 4640~4646은 모두 `mysql.rds_heartbeat2` heartbeat INSERT/UPDATE 후 COMMIT. 7개 구간에 다른 Query·DDL·트랜잭션 없음. 원본 binlog 출력은 정현 보관(희재 미확인)
- **RPO (정현 보고)**: Fence 직전 마지막 저장(11:36:44.209, `completed=0`)이 승격 전(11:45:05) `db-primary`에서 `step_id=442 PENDING`, `updated_at=11:36:44.184739`로 같은 저장 상태. 이후 재개 k6가 같은 행을 다시 토글해 현재 `updated_at`은 근거로 쓰지 않음
- **저장 후 재조회 (정현 보고)**: 승격 후 제한 쓰기 → 별도 연결 재조회 → MaxScale 경유 재조회 일치, 온프렘 웹에서 상태 변경 후 새로고침 유지. k6 로그는 조회가 저장보다 앞이라 이 재조회를 입증하지 못함

## 5. Terraform Plan 불일치 발견

## 7. 판정

- 사이트 전환(DNS)은 17.8초/약 23.8초, 사용자 읽기 경로에 지속 장애 없음(독립 관측 범위 내)
- 쓰기는 안전을 위해 **의도적으로 보류**했고 보류 사유(GTID 증가)와 확인 근거(heartbeat)가 있음 → 자동화 성능과 운영 판단 지연을 분리해 보고
- PR #27 병합 후 k6 쓰기 안정 시작까지 67.5초(30초 연속 성공 확인은 12:31:21.906), Apply로 가중치 ROSA 0 / 온프렘 1 고정, HC 반전 해제
- **복귀는 T8**에서 수행(별도 결과 문서)

## 8. 한계·미확인

- STOP 요청 시각 미기록 → 보류 시간만 따로 산출하지 않음
- 예린 Apply 시작·종료 초 단위, 온프렘 신규 Pod Ready 초 단위(보고는 12:30:51), T_sync는 미수령
- 단일 관측점(DevOps probe + Infra Fence 루프), 5초 해상도라 1초 단발은 놓칠 수 있음. 1 VU·계정 1개
- probe 단발 비정상(app 21 / dr 28)과 `auth='-'` 41행의 원인 미확인(probe VM 순간 끊김 가능성, 추정)
- Route 53 전환 직후 약 6초 rosa↔onprem 왕복 원인 미확정
- 이 시연은 ROSA 쓰기 차단 + DB 승격 + DNS 전환을 한 시나리오로 연결했지만 "ROSA 클러스터 자체가 없어진 경우"는 시험하지 않음
- 테스트 계정 이메일·IP·HC ID는 이 문서에 적지 않음
