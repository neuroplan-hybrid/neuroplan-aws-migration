# T7 인증서 CA 전환 무중단 (범위 A) — 실측 결과 (2026-10-16)

> **판정: 표본 기반 인증서 교체·원복 연속성 PASS (실측 범위 내).** 단, 런북 4.5~4.7이 요구하는 **원복 후 2분 관측은 미충족**(TLS 표본 약 72초, k6 약 38초)이며 재측정하지 않았으므로 전체 절차 조건까지 완료했다고 표현하지 않는다. 미리 받아 둔 ZeroSSL 인증서로 온프렘 TLS Secret을 수동 교체(Let's Encrypt → ZeroSSL)하고 원복하는 동안, 새 연결마다 인증서를 검증하는 TLS 표본과 k6 로그인·조회·저장 모두 **실패 0건**이었다.
>
> **중요:** 이 테스트는 CA 장애 시연이나 RTO 측정이 아니다. **수동 교체 절차가 요청을 끊지 않는지**의 연속성 검증이다(결정 #63 A안 유지). 측정 경로는 **온프렘 VIP 직접**이며 실제 사용자 경로(공인 DNS → DR NLB → VPN → VIP)는 통과하지 않는다.

기준: [통합 장애 시연안 PR #123](https://github.com/neuroplan-hybrid/neuroplan-aws-migration/pull/123)의 번호 체계(T7 인증서 CA 전환), 런북 `docs/runbooks/cert_ca_switch_continuity_1008.md`. 시각은 KST. 계정 ID·IP·테스트 계정 이메일·인증서·키는 적지 않는다.

## 4. 한계

1. **1회차 TLS 표본 미가동**: 교체 직후 약 1분(15:34:43~15:35:43)의 Issuer 전환 증적이 없다(k6에는 포함, 실패 0건). 정식 증적은 2회차.
2. 원복 후 관측이 런북 4.5~4.7의 2분 조건에 못 미쳤다(**조건 미충족**): TLS 표본 약 72초, k6 약 38초. 재측정은 하지 않았다.
3. 측정 경로는 **온프렘 VIP 직접**이다. DR NLB·VPN 경로는 통과하지 않는다.
4. 표본 간격이 약 1초(호스트별 최대 1.024·1.039초)라 표본 사이의 순간 실패는 배제할 수 없다.
5. 1 VU·테스트 계정 1개, 단일 관측점(Infra VM).
6. `T_k6_end`는 수기 근사값(15:46:21), 정확값은 CSV 마지막 행 기준.
7. 1회차 ZeroSSL 유지(약 2분 14초)는 런북 기준(3분)보다 짧다.
