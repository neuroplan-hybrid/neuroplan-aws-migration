# T8 Failback (온프렘 DR → ROSA 복귀) — 실측 결과 (2026-10-16)

> **판정: 기술 검증 PASS (실측 범위 내).** T6 이후 DR 상태(ROSA 0 / 온프렘 1)에서 온프렘 쓰기를 먼저 멈추고, 데이터를 백업·스냅샷으로 보존한 뒤 RDS를 단일 Writer로 확정하고 온프렘 DB 2대를 RDS에서 다시 채웠다. ROSA 쓰기를 열고 **마지막에** Route 53 가중치를 ROSA 1 / 온프렘 0으로 되돌렸다. 하드 스톱(18:49:24) 안에 종료했고, 가중치 복귀 후 k6 2분 213요청·284 check에서 실패는 없었다.
>
> **중요:** 가중치만 되돌리는 방식으로는 복귀할 수 없다. T6 이후 `db-primary`에 RDS에 없는 자체 GTID(`1-1-3077`~`1-1-4721`, 1,645건)가 쌓여 복제를 그대로 재개하면 두 이력이 합쳐질 위험이 있었다. 그래서 **순서를 고정한 수동 절차**로 진행했다.

기준: [통합 장애 시연안 PR #123](https://github.com/neuroplan-hybrid/neuroplan-aws-migration/pull/123)의 번호 체계(T8 Failback). 시각은 KST이며, 희재 시각은 서버 로그·CSV(`~/t8_times.log` 등), 정현·예린 시각은 메시지 보고 기준이다. **손으로 입력한 시각은 입력 지연이 있어 시스템 로그(Terraform 출력·Argo 이력)와 추후 대조한다.** 계정 ID·IP·HC ID·엔드포인트·테스트 계정은 적지 않는다.

## 1. 순서와 안전 기준

1. 온프렘 Fence=true (gitops #28) → 실제 쓰기 503 확인 = **T_freeze**
2. `db-primary` 최종 증적·일관 백업 + RDS 수동 스냅샷
3. `db-primary` 기준 RDS 재동기화 → RDS 단일 Writer 확정 → `db-primary`·`db-replica`를 RDS에서 재시드(RDS → 온프렘 단방향 복제)
4. ROSA Fence=false (gitops #29) → ROSA 검증
5. 새 Terraform Plan-only 재검증 → 정현·예린 승인
6. Route 53 ROSA 1 / 온프렘 0 (#133) 병합·Apply → k6 로그인·조회·저장·재조회

- **하드 스톱 = T_freeze + 90분 = 18:49:24.** 초과하면 병합·Apply 없이 현재 상태를 유지한다(정현). 재시드(3)부터는 온프렘 데이터가 덮어써져 "DR 상태 유지"로 되돌릴 수 없다.
- 가중치 복귀를 **맨 마지막**에 둔다: HC가 healthy가 되면 Route 53이 재동기화 전에 ROSA로 되돌릴 위험을 막기 위해서다.
- 보존 대상: `db-primary`의 `1-1-3077`~`1-1-4721`(1,645건)은 폐기하지 않고 백업·스냅샷으로 보존했다.

## 5. 한계·미확인

- 손 입력 시각(T_freeze 등) 입력 지연 포함. 17:18:08에 기록된 `T_freeze_503_confirmed`는 실제 확인 전 사전 입력이라 무효로 하고 17:19:24를 사용
- 예린 Apply 시작·종료 초 단위·Terraform 출력, `T_freeze` 공개 경로 PATCH 503 **원본 증적**(요청 시각 포함) 미수령
- 정현 k6 CSV 파일명·sha256, DB 단계별 초 단위(재시드 외) 일부 미수령. 정현 PATCH 반영 확인(`plan_steps.id=451`)은 정현 보고 기준
- 관측 파일 경계: 터널 1차 끝 17:11:36 / 2차 시작 17:12:20, HC_DR 17:12:09 / 17:12:17 (모두 병합 시작 17:17:56 이전). HC·probe 2차 파일 첫 데이터 행 미확인
- 단일 관측점(DevOps probe + Infra 로그), 1 VU k6, 행 수 일치까지 확인
- **롤백 정책 미기록**: RDS 단일 Writer 이후 DNS만 0/1로 되돌리면 온프렘 DB가 `read_only=1`이라 쓰기가 실패한다(예린 지적). 합의된 것은 "하드 스톱 초과 시 병합·Apply 없이 현재 상태 유지"뿐이다. fail-forward와 읽기 전용 폴백 중 어느 쪽인지, 단계별 되돌림 표는 팀이 정해 이 문서에 반영한다
- ROSA 클러스터 자체가 없는 경우는 시험하지 않았고, 이번에는 문제 없이 완료되어 롤백 경로를 실제로 쓰지 않았다
